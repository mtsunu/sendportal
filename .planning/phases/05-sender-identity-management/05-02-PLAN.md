<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser → edit/delete routes | Untrusted sender ID, form fields, CSRF token, and method override cross the web boundary. |
| Authenticated member → shared workspace library | Any current-workspace member is intentionally allowed to mutate shared records, but only inside that workspace. |
| Host → vendor layout | Host-provided navigation HTML crosses into the package-rendered sidebar. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-05-05 | Elevation of privilege | Edit/update/destroy lookup | high | mitigate | Relation-scoped findOrFail for all actions plus explicit foreign-ID 404 tests. |
| T-05-06 | Tampering | Update/delete forms | high | mitigate | Form Request validation, CSRF, method spoofing, validated fields only, and confirmation before DELETE. |
| T-05-07 | Information disclosure | Error/status behavior | high | mitigate | Foreign records are never globally fetched; return 404 rather than 403 or explanatory response. |
| T-05-08 | Tampering | Migration/model tenancy key | high | mitigate | Database foreign key/index and relation-created workspace_id prevent orphaned or request-selected ownership. |
| T-05-09 | Information disclosure | Sender labels/names/emails in Blade | medium | mitigate | Normal escaped Blade interpolation; no raw output for sender data. |
| T-05-SC | Tampering | npm/pip/cargo installs | high | accept | No package-manager install task exists; existing Composer graph and security controls remain unchanged. |
</threat_model>
