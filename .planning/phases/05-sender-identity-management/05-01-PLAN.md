<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser → host web routes | Untrusted authenticated form fields and sender IDs enter Laravel's web middleware. |
| Current user → workspace relation | A user-controlled URL or form must not select another workspace's sender. |
| Host → SendPortal Core sidebar seam | Host HTML is injected into a vendor-rendered sidebar without editing vendor code. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-05-01 | Elevation of privilege | SendersController sender lookup | high | mitigate | Require auth/verified/RequireWorkspace and use currentWorkspace()->senders() for every sender query; Plan 02 asserts foreign IDs return 404. |
| T-05-02 | Tampering | Sender store request and migration | high | mitigate | Validate only label/from_name/from_email, assign workspace_id through the relation, normalize input, and use CSRF-protected web forms. |
| T-05-03 | Information disclosure | Foreign sender response | high | mitigate | Never globally bind or find sender IDs; relation-scoped findOrFail makes another workspace indistinguishable from missing. |
| T-05-04 | Tampering | Blade sender fields/sidebar | medium | mitigate | Escape sender values with normal Blade output and render only trusted host fragments through the established resolver. |
| T-05-SC | Tampering | Composer/package installs | high | mitigate | No package install task; retain the existing lock/security policy and verify no vendor edits. |
</threat_model>
