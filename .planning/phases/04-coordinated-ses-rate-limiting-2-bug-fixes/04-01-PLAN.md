# Interface notes for the executor
# - Redis::throttle($key) returns Illuminate\Redis\Limiters\DurationLimiterBuilder.
#   Chain: ->allow(int $rate)->every(1)->block(int $seconds)->sleep(int $ms)->then(callable $ok, ?callable $onFail).
#   then() runs $ok inside the acquired 1-second window; on block timeout it calls $onFail
#   if given, else throws Illuminate\Contracts\Redis\LimiterTimeoutException.
# - SesMailAdapter exposes protected helpers to REUSE (never call parent::send()):
#   resolveClient(): SesClient, resolveMessageId(Result): string, getSendQuota(): array, $this->config (array).
# - ThrottledSesAdapter::send() MUST preserve the parent's exact signature and return type:
#   send(string $fromEmail, string $fromName, string $toEmail, string $subject,
#   MessageTrackingOptions $trackingOptions, string $content): string. Import
#   Sendportal\Base\Services\Messages\MessageTrackingOptions. A shorthand `send(): string`
#   would be an incompatible-signature fatal against the parent.
# - Aws\Ses\Exception\SesException: getAwsErrorCode() reads $context['code'] (the outer detection
#   gate: === 'Throttling'). getMessage() is a VERBOSE wrapper ("Error executing SendEmail…") —
#   do NOT match on it. The clean AWS wording lives in getAwsErrorMessage() (reads
#   $context['message']); the production sub-branch matches on getAwsErrorMessage(). Construct in
#   tests as new SesException($awsMessage, $commandMock, ['code' => 'Throttling', 'message' => $awsMessage])
#   — set BOTH the constructor $message and context['message'] to the AWS text
#   ("Maximum sending rate exceeded." / "Daily message quota exceeded.") so getAwsErrorMessage()
#   returns exactly the field production reads.
# - Aws\Result is array-constructible: new Aws\Result(['MessageId' => 'id']) / new Aws\Result(['MaxSendRate' => 14.0]).
# - MailAdapterFactory::$adapterMap is public static; EmailServiceType::SES === 1.
# - Test env (phpunit.xml.dist): CACHE_DRIVER=array (Cache::lock/remember work in-process),
#   QUEUE_DRIVER=sync. The Redis limiter tests use the 'default' Redis connection and must
#   skip cleanly when Redis is unreachable (documented residual risk).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
