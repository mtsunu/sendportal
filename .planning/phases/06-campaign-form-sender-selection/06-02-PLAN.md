| Boundary | Description |
|---|---|
| Active workspace → rendered campaign form | Tenant-scoped database rows become visible option data. |
| User-controlled identity fields → HTML attributes/text | Sender values may contain quotes, markup, or unusually long content. |
| Browser autofill → submitted campaign fields | Client behavior copies convenience data into the package's validated editable inputs. |
| Published host views → upgraded vendor package | Override drift can remove package behavior or expose an availability break. |
