### Interaction contract

- **Load:** Create and edit both show the same picker before the existing From Name field. The first option is blank and visibly prompts `Choose a saved sender`; no sender is selected from campaign values.
- **Select:** On native `change`, read the selected option's escaped `data-from-name` and `data-from-email` values and copy them into the existing `input[name="from_name"]` and `input[name="from_email"]` controls. The selected option itself is not submitted.
- **Edit after select:** Inputs remain enabled, focusable, and manually editable. A subsequent manual edit is preserved until the user selects another sender. Choosing the blank option clears both From fields, matching the convenience selector's reset behavior.
- **Submit:** The package form still submits only its existing named fields and still requires `from_name` and `from_email`. The picker must not add `sender_id`, a hidden sender identity, or a new validation rule.
- **No saved senders:** The picker remains enabled with the blank option; no special warning or link is shown. Users can type From Name and From Email directly.
- **Error/reload:** Existing package validation errors and old input remain authoritative after a failed submit. Do not auto-select a sender or overwrite old input on page load.

### Verification criteria

1. Rendered create and edit forms contain one `select#campaign-sender-picker` with Bootstrap `form-control`, a real label, no `name`, and first `<option value="">Choose a saved sender</option>` with no `selected` attribute.
2. Options contain only the active workspace's senders, are ordered by label, display exact `Label — from@example.com` text, and safely render quotes/HTML characters.
3. With zero senders, the select remains enabled and the existing From fields remain present and usable.
4. Browser verification confirms selecting a sender fills both From fields, selecting blank clears both, and manual edits remain possible afterward; create and edit are both checked.
5. Edit verification confirms existing campaign From values are preserved on initial render and no sender is pre-selected.
6. Focused PHPUnit/rendered assertions cover create, edit, empty, workspace isolation, escaping, and absence of a submitted sender field; full PHPUnit suite and `git diff --check` pass.
7. `git diff --name-only -- vendor/mettle/sendportal-core` is empty; only the host seam, host package-view overrides, and planned tests are changed.
