## Trust Boundaries

| Boundary | Description |
|---|---|
| tracked workflow/shell scalar → outer command parser | Supported command text is untrusted and can place an evaluator where the current parser expects the final executable. |
| outer bash/sh/zsh/eval invocation → nested payload | Quotes, escapes, expansion, substitution, nesting, and unsupported argv can conceal or change the command that executes. |
| recursive classifier → route failure records | Bounds or parse errors must yield deterministic failure evidence rather than exceptions, zero records, or silent skips. |
| disposable fixture Git roots → production route evidence | Adversarial regression commands must exercise the production parser without satisfying the real CI/README evidence requirement. |
