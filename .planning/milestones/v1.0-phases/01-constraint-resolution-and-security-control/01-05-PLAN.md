## Trust Boundaries

| Boundary | Description |
|---|---|
| repository checkout → Composer distribution | The checked-in PHAR and reviewed checksum record define the only Composer implementation the guard may execute. |
| caller environment → guard | PATH, COMPOSER_BIN, Composer override variables, and command arguments are untrusted input before dependency resolution. |
| tracked source/documentation → route audit | Every mutation-looking command is parsed as a chain of invocations; file context determines whether it is an executable/operator route. |
| Composer policy engine → package and advisory services | Mutable package/advisory data is evaluated by the committed native policy, including the exact D-02 exception boundary. |

## STRIDE Threat Register (ASVS L1)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-15 | Tampering | PATH, COMPOSER_BIN, cached, missing, or altered Composer binary | critical | mitigate | Resolve one repository-relative PHAR only; validate its committed SHA-256 record and exact version before any PHP subprocess, and regression-test a compliant-looking PATH shadow that is never executed. |
| T-01-16 | Tampering | Composer native policy capability | high | mitigate | After integrity/version checks, invoke policy help through PHP_BINARY and fail before delegation if the trusted distribution lacks capability. |
| T-01-17 | Tampering | CI/operator command chains | critical | mitigate | Tokenize each logical command chain and fail every direct Composer mutation in a supported route independently of adjacent guarded segments. |
| T-01-18 | Repudiation | Route-audit evidence | medium | mitigate | Emit deterministic records per invocation segment and run negative cases in a disposable Git root excluded from the production inventory. |
| T-01-19 | Denial of service | Composer distribution unavailable or damaged | medium | mitigate | Fail with a fixed actionable diagnostic before resolution; do not fetch, select PATH, or use a cache fallback at invocation time. |
</threat_model>
