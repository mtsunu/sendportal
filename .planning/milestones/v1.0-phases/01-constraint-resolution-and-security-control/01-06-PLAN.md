<interfaces>
The existing guard exposes three behavior seams that this plan must preserve and harden:
- `repositoryDistributionPaths(): array{phar: string, record: string}` derives the trusted distribution from the canonical script location.
- `rejectOverrides(list<string> $arguments): void` runs before `verifiedComposerPath()` and therefore before any Composer process.
- `runComposer(list<string> $command): array{int, string}` currently calls `proc_open` without a cwd; Plan 06 must make the canonical repository root an explicit required argument or equivalent invariant for every call.

The route audit's public execution seam is `php tests/Composer/ComposerPolicyGuardTest.php --route-audit`. It enumerates only `git ls-files -z`, normalizes logical lines, segments shell command lists, parses an invocation, classifies that invocation by tracked path, and fails on `unclassified` or `unsupported` production records.
</interfaces>
